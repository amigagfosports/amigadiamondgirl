# Diamond Girl for GFOS

Lucy the Diamond Girl (Boulder Dash-like puzzle, GPL, Peanhua/diamond-girl or the classic Joni Yrjana sources) for GFOS: AmigaOS 3.2 with GFOpenUp, on a 68040/68060 with FPU, using GFOpenUp's SDL2.module (and SDL2_image / SDL2_mixer as needed) and GFOpenGPU.

Target: Cradle boards / os32-gcc16-open6 stove.

## Status

Intake branch. Source pin and first stove build still to do.

## Build target

    STOVE=~/AmiCradle/stoves/os32-gcc16-open6

Uses shared OpenUp libraries (LIBS:GFOpenGPU/SDL2.module). Data path PROGDIR:. 68040 fit expected for this 2D title.

Designed, tested and delivered by The AmiCradle Team.
